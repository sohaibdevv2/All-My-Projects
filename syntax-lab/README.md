# Syntax Lab for Library System

This project provides a side-by-side comparison of **Fundamental Programming Syntax**. By looking at the same "Library System" logic in 4 different languages, you can see how each handles data, loops, and user input.

## Syntax Focus Areas
*   **Python:** Indentation logic & dynamic typing.
*   **C#:** Object-Oriented structure & strict typing.
*   **C++:** Manual memory management & pre-processor directives.
*   **Node.js:** Asynchronous events & object literals.

## Commands to Run
| Language | Command |
| :--- | :--- |
| **Python** | `python python-app/main.py` |
| **C#** | `cd csharp-app && dotnet run` |
| **C++** | `g++ cpp-app/main.cpp -o app && ./app` |
| **Node.js** | `node node-app/index.js` |

## Comparison Table
| Feature | Python | C# / C++ | Node.js |
| :--- | :--- | :--- | :--- |
| **Block Start** | Colon `:` | Brace `{` | Brace `{` |
| **End of Line** | Nothing | Semicolon `;` | Semicolon `;` |
| **Variable Declaration** | `name = "x"` | `string name = "x"` | `const name = "x"` |
