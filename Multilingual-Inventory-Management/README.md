# Multilingual Inventory Management System

This project demonstrates a Simple Inventory System implemented in four different programming languages.

## Project Structure

### 1. Python (`/python-app`)
- **Focus:** Readability and native dictionaries.
- **Run:** `python python-app/main.py`

### 2. C# (`/csharp-app`)
- **Focus:** OOP principles and .NET Lists.
- **Run:** `dotnet run --project csharp-app/Program.cs`

### 3. C++ (`/cpp-app`)
- **Focus:** Performance and STL Vectors.
- **Run:** `g++ cpp-app/main.cpp -o inventory && ./inventory`

### 4. Node.js (`/node-app`)
- **Focus:** Asynchronous logic/Readline.
- **Run:** `node node-app/index.js`

## How to use in Cloud IDEs
1. Clone this repo: `git clone <your-repo-url>`
2. Navigate into the specific language folder.
3. Run the commands listed above.👆
