<h1>Synapse - AI Conversational Chat</h1>

<p>
  Synapse is a modern, responsive, and intuitive web-based chat application designed to showcase the power and capabilities of the <b>Google Gemini API</b>. It serves as a demonstration of how to integrate a powerful Large Language Model (LLM) into a user-friendly frontend interface, providing a seamless conversational experience.
</p>

<h2>Purpose</h2>
<p>
  The primary goal of this project is to test and demonstrate the advanced features of the <b>Google Gemini API</b>, specifically the <code>gemini-2.5-flash</code> model. It aims to highlight:
</p>
<ul>
  <li><b>Real-time Interaction:</b> Streaming responses from the AI to create a fluid and dynamic conversation.</li>
  <li><b>Rich Content Formatting:</b> The AI's ability to generate and display formatted content like code blocks, lists, and other markdown elements.</li>
  <li><b>Ease of Integration:</b> How the <code>@google/genai</code> SDK can be cleanly integrated into a modern React application.</li>
  <li><b>Quality of AI:</b> The quality, speed, and helpfulness of the responses generated by the Gemini model.</li>
</ul>

<h2>Features</h2>
<ul>
  <li><b>Real-time Streaming:</b> Messages from the AI are streamed token-by-token, providing immediate feedback.</li>
  <li><b>Markdown Support:</b> Renders bold text, italics, code blocks, and more for clear and structured responses.</li>
  <li><b>Responsive Design:</b> A clean and modern UI that works seamlessly on both desktop and mobile devices.</li>
  <li><b>Error Handling:</b> Provides clear feedback to the user in case of API errors.</li>
  <li><b>Easy to Use:</b> A simple, single-page interface focused on the conversation.</li>
</ul>

<h2>Tech Stack</h2>
<p>
  This project is built with a modern, lightweight tech stack, avoiding complex build configurations.
</p>
<ul>
  <li><b>Frontend Library:</b> <b>React</b> with TypeScript for a robust and type-safe component-based architecture.</li>
  <li><b>AI Integration:</b> <b>Google Gemini API (<code>@google/genai</code>)</b> using the <code>gemini-2.5-flash</code> model for fast and high-quality chat completions.</li>
  <li><b>Styling:</b> <b>Tailwind CSS</b> for a utility-first approach to building a custom and responsive design.</li>
  <li><b>Module System:</b> Native <b>ES Modules</b> with <code>importmap</code> for dependency management directly in the browser, using <code>esm.sh</code> as a CDN. This demonstrates a modern, buildless development approach.</li>
</ul>

<h2>Getting Started</h2>
<p>
  To run this application, you need a valid Google Gemini API key.
</p>
<ol>
  <li><b>API Key:</b> The application is designed to securely access the API key from a <code>process.env.API_KEY</code> environment variable, which must be configured in the execution environment.</li>
  <li><b>Serve the Files:</b> Open the <code>index.html</code> file in a compatible web browser or serve it using a local static file server.</li>
</ol>
<p>
  The application will initialize the chat session and be ready for interaction.
</p>
