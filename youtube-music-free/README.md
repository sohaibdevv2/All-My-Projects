# 🎵 **Free YouTube Music**
<img width="1917" height="1080" alt="image" src="https://github.com/user-attachments/assets/90816c33-2dd4-4cb6-929c-de936210c317" />

This app streams audio directly from YouTube Music. No login, no premium account, no ads - just music.

---

## 🔥 Features

- **No ads** - enjoy uninterrupted music  
- **Background playback** - music keeps playing even when the window is minimized  
- **Search** - find tracks, artists, albums instantly  
- **Playlists** - create and save your own playlists locally (no account sync)  
- **Dark theme** - easy on the eyes, switches automatically  
- **Media keys** - control playback with your keyboard (Play/Pause, Next, Previous)  
- **Portable** - just one EXE file, no installation, no registry mess  

---

## 📦 Download & Install

1. Go to the **Releases** section and download the archive:  
   `youtube-music-free.zip`

2. The archive is **password-protected**. Use this password to extract it:  
   🔐 **Password:** `ytm4all`

3. Inside the archive you'll find a single file:  
   `youtube-music-free.exe`

4. Double‑click it to run - that's it. No installation wizard, no dependencies.

> 💡 **Tip:** You can move the EXE anywhere - your desktop, a USB stick, or a folder. It doesn't write anything to the system.

---

## 🖥️ How to use

- **Search** - type anything in the search bar and press Enter.  
- **Play** - click any track from the results.  
- **Queue** - double‑click to add to the queue, or use the context menu.  
- **Playlist** - click the `+` icon to save the current queue as a playlist.  
- **Volume** - scroll over the volume icon or use the slider.  
- **Minimize** - click the minimize button; playback continues in the background.

All controls are intuitive - no learning curve.

---

## ❓ Antivirus false positive?

Some antivirus software may flag `youtube-music-free.exe` because it's built with PyInstaller and doesn't have a digital signature. This is a **false positive**.  

If you downloaded the file from this official repository, you can safely add it to your antivirus exceptions.
