## 🎯 What Is This?

**Game of DSA** is a full-featured, visually rich educational game built in **C++17 with Raylib**. Instead of staring at textbook diagrams, you *step inside* the algorithm.

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   📚 Traditional Learning          🎮 Game of DSA          │
│   ─────────────────────           ──────────────────        │
│   • Read about arrays              • Walk through           │
│   • Draw diagrams on paper           Array Forest           │
│   • Memorize Big-O tables          • Watch live             │
│   • Hope you understand              particle effects       │
│   • Get bored after 5 min          • Earn XP & level up     │
│                                    • Actually remember it    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 🌟 Key Highlights

- 🎮 **8 fully playable DSA worlds** — each themed to reinforce the concept
- ⚡ **Real-time algorithm animation** — watch every step execute live
- 💎 **Cyber-futuristic UI** — neon glows, glass panels, particle effects
- 🔐 **Firebase Auth** — login, save progress, compete on leaderboards
- 🌐 **Runs in browser** — compiled to WebAssembly via Emscripten
- 📱 **Cross-platform** — macOS, Linux, Windows desktop builds
- 🚀 **CI/CD** — auto-deploys to GitHub Pages on every push to `main`
- 🏆 **XP & Leveling** — real progression system with unlockable worlds

## 🖥️ Build for Desktop (macOS)

### ✅ Step 1 — Check Prerequisites

Open **Terminal** and run:

```bash
# Check CMake
cmake --version
# Need: cmake version 3.16 or higher

# Check compiler
clang++ --version
# Need: Apple Clang 12+ or Clang 11+

# Check git
git --version
```

If CMake is missing, install it:
```bash
# Option A — Homebrew (recommended)
brew install cmake

# Option B — Download from cmake.org
# https://cmake.org/download/
```

### 📥 Step 2 — Clone the Repository

```bash
# Clone with all submodules
git clone https://github.com/sohaibdevv/Game-of-DSA.git

# Move into the project folder
cd Game-of-DSA

# Check that all files are present
ls -la
```

You should see: `CMakeLists.txt`, `src/`, `assets/`, `web/`, `scripts/`, `docs/`

### 🔨 Step 3 — Build Using the Build Script (Easiest)

```bash
# Make the build script executable
chmod +x scripts/build.sh

# Build in Release mode (optimized, fast)
./scripts/build.sh

# OR build in Debug mode (has debug symbols)
./scripts/build.sh debug
```

The script will:
1. 📦 Create `build/` directory
2. 🔧 Run CMake configuration (auto-downloads Raylib 5.0)
3. ⚙️ Compile all source files
4. ✅ Output the binary at `build/GameOfDSA`

### 🎮 Step 4 — Run the Game

```bash
./build/GameOfDSA
```

A window opens at 1280×720. You're in! 🎉

### 🔨 Alternative — Build Manually with CMake

```bash
# Step 1: Configure (first time takes 2-3 min, downloads Raylib)
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Step 2: Compile (uses all CPU cores)
cmake --build build --parallel

# Step 3: Run
./build/GameOfDSA
```

```bash
# Load emscripten environment

  -DCMAKE_BUILD_TYPE=Release \

# Build

# The build produces:
# build-web/index.html

# build-web/index.wasm
# build-web/index.data  (assets bundled)
```

### 🌐 Step 4 — Test Locally

```bash
# Python's built-in server (needs COOP/COEP headers for SharedArrayBuffer)

```

Then open: `http://localhost:8080`

### 🚀 Step 5 — Deploy to GitHub Pages

```bash
# Copy WASM build to docs/
cp build-web/index.html docs/index.html

cp build-web/index.wasm docs/index.wasm

# Commit and push — GitHub Actions deploys automatically!
git add docs/

```

The GitHub Actions workflow detects the push and deploys in ~30 seconds.

### ⚙️ GitHub Actions — Automatic Deployment

The CI/CD pipeline (`.github/workflows/deploy.yml`) has **two independent jobs**:

```
Push to main
     │
     ├── Job 1: deploy-web (runs first, ~30 seconds)
     │          └── Deploys docs/ to GitHub Pages immediately
     │              (the interactive JS demo is always live)
     │
     └── Job 2: build-wasm (runs in parallel, ~15-20 minutes)
                └── Tries to compile C++ → WebAssembly
                    If successful: copies WASM files to docs/
                    If it fails: does NOT block deployment
```

> 💡 This means your game is **always live** on GitHub Pages, even if the Emscripten build fails.

## 🔥 Firebase Setup

Firebase provides **authentication** (login/register) and **cloud data** (progress save + leaderboards).

> 💡 Firebase is **optional** — the game runs in demo mode without it. All 8 worlds work fully without any Firebase connection.

### 📋 Step 1 — Create a Firebase Project

1. Go to [console.firebase.google.com](https://console.firebase.google.com)
2. Click **"Add project"**
3. Enter a name, e.g. `game-of-dsa`
4. Disable Google Analytics (not needed)
5. Click **"Create project"**

### 🔐 Step 2 — Enable Authentication

1. In the Firebase Console sidebar → click **Authentication**
2. Click **"Get started"**
3. Under **Sign-in method** tab → click **Email/Password**
4. Toggle **Enable** → click **Save**

### 🗄️ Step 3 — Create a Realtime Database

1. In the sidebar → click **Realtime Database**
2. Click **"Create database"**
3. Choose **your region** (pick one close to you)
4. Start in **test mode** (you can secure it later)
5. Click **"Done"**

### 🔑 Step 4 — Get Your API Keys

1. In the sidebar → click the ⚙️ **gear icon** → **Project settings**
2. Scroll to **"Your apps"** section
3. Click **"Add app"** → choose **Web (</>)**
4. Register the app with any nickname
5. Firebase shows you a config block like:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",
  authDomain: "game-of-dsa.firebaseapp.com",
  databaseURL: "https://game-of-dsa-default-rtdb.firebaseio.com",
  projectId: "game-of-dsa",
  ...
};
```

Copy these values — you need `apiKey`, `projectId`, and `databaseURL`.

### ✏️ Step 5 — Update the C++ Source

Open `src/firebase/Firebase.h` and update these constants:

```cpp
static constexpr const char* PROJECT_ID  = "game-of-dsa";       // ← your projectId
static constexpr const char* API_KEY     = "AIzaSyXXXXXXXX..."; // ← your apiKey
static constexpr const char* DB_URL      = "https://game-of-dsa-default-rtdb.firebaseio.com"; // ← databaseURL
```

### 🌐 Step 6 — Update the Web Shell

Open `web/shell.html` and find the Firebase config comment section, then add your config:


In Firebase Console → **Realtime Database** → **Rules**:

### 🧩 Adding a New World

Follow these 4 steps:

**Step 1:** Create `src/worlds/YourWorld.h`:
```cpp
#pragma once
#include "World.h"

class YourWorld : public World {
public:
    void Init(GameContext& ctx) override { /* setup */ }
    void Update(GameContext& ctx, float dt) override { /* logic */ }
    void Draw(GameContext& ctx, Font font) override { /* rendering */ }
    void Cleanup() override { /* teardown */ }
    Screen GetID() const override { return Screen::YOUR_WORLD; }
};
```

**Step 2:** Add to `src/core/GameState.h` Screen enum:
```cpp
enum class Screen {
    // ...existing screens...
    YOUR_WORLD,
};
```

**Step 3:** Register in `src/core/Game.cpp`:
```cpp
#include "../worlds/YourWorld.h"

void Game::RegisterScreens() {
    // ...existing registrations...
    screens[Screen::YOUR_WORLD] = std::make_unique<YourWorld>();
}
```

**Step 4:** Add card in `src/screens/WorldSelect.h` worlds vector.

## ❓ FAQ

<details>
<summary><b>🌐 Why isn't the game loading on GitHub Pages?</b></summary>

If you see a blank page, check:
1. Go to your repo **Settings → Pages**
2. Set **Source** to **GitHub Actions** (not a branch)
3. Wait for the **deploy-web** workflow to finish (check Actions tab)
4. The page URL is: `https://YOUR_USERNAME.github.io/Game-of-DSA`

</details>

<details>
<summary><b>🔨 CMake says "cannot find Raylib"</b></summary>

Don't worry — CMake automatically downloads Raylib 5.0 using FetchContent on the first build. Just make sure you have internet access during the first `cmake -B build` command. It takes 2-3 minutes.

If it still fails:
```bash
# Clear the cache and retry
rm -rf build/
cmake -B build -DCMAKE_BUILD_TYPE=Release
```

</details>

<details>
<summary><b>🔥 Firebase login isn't working</b></summary>

1. Make sure you updated `PROJECT_ID` and `API_KEY` in `src/firebase/Firebase.h`
2. Make sure **Email/Password authentication** is enabled in Firebase Console
3. On desktop, libcurl must be installed (`sudo apt-get install libcurl4-openssl-dev`)
4. Check Firebase Console → Authentication → Users to see if the account was created

The game works perfectly without Firebase — just use **Continue as Guest**.

</details>

<details>
<summary><b>🌐 Emscripten build fails with strange errors</b></summary>

1. Make sure you activated Emscripten: `source ~/emsdk/emsdk_env.sh`
2. Use exactly version `3.1.50` (other versions may have incompatibilities)
3. Delete the build dir and retry: `rm -rf build-web && ./scripts/build.sh web`
4. Check that you have at least **4GB RAM** free — WASM compilation is heavy

</details>

<details>
<summary><b>🎮 The game window doesn't open</b></summary>

On Linux, make sure display libraries are installed:
```bash
sudo apt-get install libx11-dev libxrandr-dev libgl1-mesa-dev
```

On macOS, grant the app access in **System Preferences → Security & Privacy**.

</details>

<details>
<summary><b>⚡ Can I add more sorting algorithms?</b></summary>

Yes! Open `src/worlds/SortingArena.h`. The algorithm pre-computes all steps into a `steps` vector, then plays them back. Add a new `ComputeXXXSort()` function that pushes `SortStep{type, i, j}` entries, then wire it to a new button.

</details>

<details>
<summary><b>📦 How do I add a new DSA world?</b></summary>

See the [Adding a New World](#-adding-a-new-world) section in the Architecture chapter above. It's a 4-step process: create the `.h` file, add to Screen enum, register in Game.cpp, and add a card in WorldSelect.h.

</details>
